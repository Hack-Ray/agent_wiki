# Skill 0.3.0：Retrieval Gate

## 促成這次修改的觀察

| 觀察 | 來源 |
|---|---|
| 沒有指示時，Agent 用內建記憶回答，不查 Notion | [Experiment 1 第 1 輪](experiment-1-retrieval.md) |
| claude.ai 只裝外掛程式時 Skill 從未被觸發；「之前的討論」被導向內建的過去對話搜尋 | [Skill 0.2.0 回饋](skill-0.2.0-review.md) |
| 0.2.x 的 `description` 只列「我最近」「我以前」這類明示說法，沒涵蓋「替我的專案選方案」這類沒提過去、但答案受既有決策影響的問題 | 使用者 2026-11-03 V2.1 規劃討論（推論，尚無失敗紀錄） |
| 沒有「不用查」的規則，無法量測或控制誤觸發 | 同上 |

## 修改

- `SKILL.md` 新增「先判斷要不要查」表格：要查、不用查、判斷不出來時的處理。
- `description` 補上隱性情境與不需要使用的情況。
- 新增 [Bootstrap Rule](../bootstrap-rule.md)，處理 Skill 載入之前的觸發。
- 新增 [V2.1 回歸測試集](benchmark-v2.1.md)，用來量測這次修改的效果。

## 待驗證

- 主動觸發率與誤觸發率尚未量測。0.3.0 是否比 0.2.2 好，要等回歸測試跑完才能判斷。
- `description` 加入「不需要使用」的說明，是否會壓低隱性題目（M07–M10）的觸發率。
