# Skill 0.3.2：共用 Skill 區

## 目的

讓重複性工作的做法（步驟、使用者偏好、輔助腳本）可以保存並在之後的對話重用，不必每次重新摸索與被使用者糾正。

## 促成這次修改的觀察（2026-11-24，claude.ai 手機 App）

- 任務：把上一期的週報 .ppt 改成新一期內容（範例已去識別化）。
- 過程中使用者連續糾正多次：轉檔後顏色跑掉、內文變粗體、檔名格式、某類事項應放在哪一段。最後找出可行做法（直接改原檔二進位，不經轉檔）。
- 使用者要求把這套做法「整理成 skill」，存進 Personal Brain 新的「共用 Skill」區，以後共用的 skill 都放那裡取用。
- 0.3.1 的 Skill 沒有「重複性工作先查既有做法」的路由，下次同類工作不會主動去找這份做法。

## 修改

- `SKILL.md` 路由表新增一列：重複性工作或「照上次方式」處理的檔案 → 先查「共用 Skill」頁。
- 新增「共用 Skill」一節：先讀 Skill 清單與對應子頁並照做；使用者修正做法後更新子頁並讀回；要求「整理成 skill」時在該頁底下新建子頁並加入清單。
- `description` 加入重複性工作的觸發情境。
- 版本升至 0.3.2。

## 驗證

- 推論通過、未實測：下次同類工作在新對話中是否會主動查「共用 Skill」頁，待實測後補記。

## 限制

- 「共用 Skill」頁以標題搜尋定位，若使用者改頁名需同步修改本節措辭。
