# Experiment 1: Memory Retrieval

## 目的

驗證全新 AI Session 能否只靠官方 Notion connector，用自然語言找回 `Personal Brain Lab` 中的記憶。

驗收標準：10 題中至少 8 題正確（V2 規格第 10 節）。

## 測試資料

- Notion 根頁面：`Personal Brain Lab`
- 2026-10-31 建立 10 個子頁。除「Agent Wiki 架構反思」外，皆為標示 🧪 的虛構測試資料。
- 「00 — About This Brain」刻意不含目錄或關鍵字索引，用於量測無輔助的基線。

## 執行規則

1. 使用**全新 Session**，且該 Session 沒有參與建立測試頁。
2. **不要在這個 repo 的 Claude Code 中執行。** Agent 可能直接讀到本檔的答案欄。建議使用 claude.ai 網頁、手機 App，或其他目錄下的 Claude Code。
3. 一題一則訊息，照下方原文問，不要提示頁面名稱或「去 Notion 找」。
4. 不要先安裝 `personal-memory` Skill。這一輪測的是沒有 Skill 時的基線。
