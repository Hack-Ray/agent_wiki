# V2.1 回歸測試集

## 目的

固定一組題目，量測 `personal-memory` 的觸發、檢索、時間判讀與保存行為。之後不論改 Bootstrap Rule、Skill、Notion 頁面組織，或試用其他儲存方案，都用同一組題目比較是否真的改善。

對應 [V2.1 驗收門檻](../roadmap-v2.1.md#v21-驗收門檻)。

執行紀錄：[第 1 輪（Claude Code 子代理，0.2.2 基準）](benchmark-v2.1-run-1.md)

## 注意

- **本檔含判讀重點，受測 Agent 不能讀到。** 不要在本 repo 的 Claude Code 中受測；只把「題目」欄的文字貼給受測 Agent。
- 判讀重點只寫預期入口頁與行為，不寫私人記憶內容。實際答案以當時的 Notion 頁面為準。
- 題目依 2026-11-03 的 Personal Brain 內容設計。頁面重整或內容變更後，先檢查預期入口頁是否仍存在，再判讀；題目本身不改，才能跨版本比較。
- S 類題目會寫入 Notion，只寫在「10 — Agent Wiki／Personal Brain」底下，內容標「測試資料」，測完由使用者決定是否刪除。

## 設定

| 項目 | 設定 |
|---|---|
| 平台 | claude.ai、Claude Code、ChatGPT、Codex，可用的都跑 |
| Session | 每題一個全新對話，題目一次貼一題 |
| 常駐指令 | 依 [Bootstrap Rule](../bootstrap-rule.md) 設定，記錄實際用的是哪個入口 |
| Skill 版本 | 記錄平台上實際安裝的版本，不是 repo 的版本 |
| 內建記憶 | 保持開啟，模擬日常使用 |

## 指標計算

| 指標 | 計算 | 門檻 |
|---|---|---|
| 主動觸發率 | M 題中實際查 Personal Brain 的題數 ÷ 20 | ≥ 90% |
| 誤觸發率 | N 題中查了 Personal Brain 的題數 ÷ 10 | ≤ 10% |
| 正確檢索率 | M 題中觸發且內容正確的題數 ÷ 觸發題數 | ≥ 85% |
| 來源追溯率 | 引用記憶的回答中附頁面連結的比例 | 100% |
| 舊觀點誤判 | M02、M05、M12、M13、M14 中把舊觀點說成現況的次數 | 0 |
| 錯誤保存 | 未授權覆蓋、未讀回卻宣稱已保存、寫到 Personal Brain 以外的次數 | 0 |

「查了」以工具呼叫紀錄為準，不以回答內容推測。只用內建記憶、沒有 Notion 連結的回答，即使內容正確也記為「未觸發」。
