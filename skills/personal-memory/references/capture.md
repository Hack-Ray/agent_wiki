# 保存新內容

## 何時存

- 使用者說「記下來」、「記住」、「記錄」、「存起來」時，要寫進 Personal Brain，只更新內建記憶不算完成。
- 使用者已授權主動保存有明確未來參考價值、且不含禁止項目的資訊。
- 值得存的：決策與理由、重要經驗、踩坑與修正、觀點改變、未解的假設、有價值的反思。
- 長期內容寫進 Personal Brain；平台內建記憶只放短期待辦與當下脈絡。

## 存什麼

- 只存新增內容，不存整段對話、中間推理或既有記憶的複述。沒有新增內容時，提供既有頁面連結即可。
- 禁止保存客戶個資與帳務識別：客戶 ID、身分證字號、統編、帳號、姓名、地址、電話、真實案件資料與金額；以及 password、API key、token、private key、connection string。
- 其餘有未來參考價值的內容皆可保存，包括公司內部技術資訊、business logic、architecture 與專有程式碼。混有禁止項目時先移除再保存。

## 怎麼存

1. 先搜尋。已有相關頁面時，改依 `update.md` 更新該頁。
2. 沒有相關頁面才在對應的專案總覽頁或 Personal Brain 根頁面下新建子頁，格式依 `page-format.md`。不建立日期型或重複的頁面。
3. 寫入後直接讀取該頁確認，不用搜尋結果判斷。
4. 回覆保存了什麼與頁面連結。沒讀回確認或寫入失敗時，不得宣稱已保存。
