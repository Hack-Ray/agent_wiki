# 頁面格式

內容不強制格式；保留足以理解的主題、時間、情境或想法、原因，以及後續變化與來源（如有）。

## 頁面組織

- 每個專案或主題一個總覽頁，從 Personal Brain 根頁面連入。總覽放現況、時間線與子頁導覽，細節放子頁，例如架構決策、踩坑紀錄。
- 新建子頁後，在上層總覽頁的導覽加上連結。

## 每頁必備

- 一行「搜尋關鍵字：」，列出模組名、技術術語、同義詞與中英文說法。搜尋偏關鍵字比對，這行決定頁面找不找得到。
- 頁面開頭一行「整理到：日期與來源位置」，例如「整理到：2026-11-01，PR #127」。

## 寫法

- 日期用台灣時間（Asia/Taipei），格式 YYYY-MM-DD。
- 來源固定標為：使用者確認、repo（附連結）、對話整理、平台內建記憶。
- 觀點會改變的內容按日期分段，新的修正追加在後面。
