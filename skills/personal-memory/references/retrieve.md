# 查詢與回答

## 怎麼查

- 從 Personal Brain 根頁面的主題入口找到專案總覽頁，再用頁面上的「搜尋關鍵字」查細節。
- 先搜尋，只讀會影響回答的頁面，必要時讀全文。
- 搜尋偏關鍵字比對。查不到時，至少換一組關鍵字再查，例如同義詞、中英文、技術術語或產品名稱，之後才說找不到。
- 剛寫入的內容可能因索引延遲還搜不到；已知頁面時直接讀取該頁。

## 怎麼回答

- 引用記憶時附上頁面連結。
- 區分目前結論、歷史觀點與未證實推測。頁面裡標了日期的段落代表當時的想法，後面的段落可能已經修正它。
- 不把使用者原本的不確定改寫成已確定的事實。
- 記憶是當時的紀錄，不等於現在的事實；與目前證據衝突時，依目前證據判斷並指出差異。
- 引用平台內建記憶時，標明它不是來自 Personal Brain。
- 找不到就明說，不補造過去的經歷。
