# 更新既有頁面

## 補充進度

1. 讀頁面開頭的「整理到：」，只看該處之後的新資訊，不必重讀全文去重。
2. 把新內容補進對應段落，只寫真正新增的部分。
3. 更新「整理到：」為本次的日期與來源位置。

## 觀點修正

- 正文、表格、標題與狀態直接改寫成現況，讀者只讀正文就得到正確結論。
- 被推翻的舊說法移到頁尾唯一一個「舊觀點／更正紀錄」區塊，每條一行：日期、舊說法、修正原因。不要在正文旁疊附則，也不要每次修正都新增一個段落。
- 觀點演變本身就是要保存的內容時（例如對某技術看法的變化），在該區塊按日期列出，正文仍寫目前的看法。
- 原文由 Notion 版本歷史保存，不靠在頁面上保留舊段落。
- 待確認事項得到使用者確認後，可改成「已確認」並標日期與「使用者確認」。
- 不同來源說法矛盾時，兩種都記下並標來源，不自行選邊。

## 安全

- 只改與本次相關的段落，保留其他內容、子頁與連結。
- 大量刪除、覆蓋或搬移頁面前，先問使用者。
- 寫入後直接讀取該頁確認，回覆修改了什麼與頁面連結。沒讀回確認或寫入失敗時，不得宣稱已保存。
