# 更新既有頁面

## 補充進度

1. 讀頁面開頭的「整理到：」，只看該處之後的新資訊，不必重讀全文去重。
2. 把新內容補進對應段落，只寫真正新增的部分。
3. 更新「整理到：」為本次的日期與來源位置。

## 觀點修正

- 保留舊觀點與它的日期，另外追加一段修正，寫明修正日期與原因。不要直接把舊內容改寫成新結論。
- 待確認事項得到使用者確認後，可改成「已確認」並標日期與「使用者確認」。
- 不同來源說法矛盾時，兩種都記下並標來源，不自行選邊。

## 安全

- 只改與本次相關的段落，保留其他內容、子頁與連結。
- 大量刪除、覆蓋或搬移頁面前，先問使用者。
- 寫入後直接讀取該頁確認，回覆修改了什麼與頁面連結。沒讀回確認或寫入失敗時，不得宣稱已保存。
